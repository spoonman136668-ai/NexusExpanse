# Gate 6B frozen oscillator and cached-attention CPU DEV trial

Use the identical Gate 5B manifest, duplicate audit, domain split, seeds 42–44, 31 training spans, eight Markdown evaluation spans, frozen/prequential write rules, shared bounded memory, compact patch predictor and causal arbitration. Evaluate all 2,040 transitions in each independent process. No first-use data. One Linux CPU thread with deterministic PyTorch 2.10.0+cpu. Two layers, width 64, 12 epochs, 372 AdamW steps over intact 255-transition spans per architecture/seed. Identical loss, auxiliary gate weight, gradient clipping and calibration subset. Rerun original Dense cached always-on, DirectMonarch cached always-on and cached patch, standalone memory, and an additional exactly size-matched Dense cached control. The original Dense width remains a larger reference. Assert identical trainable parameter counts for the oscillator, DirectMonarch and matched Dense (25 hidden features, bias-free first dense map). Clone trained states within policy families. Give both oscillator policies calibrated FFN gates; the Gate 5 always-on and patch controls use their original fully open FFNs. This compares complete policies and does not isolate attention cost alone.

Train a raw-byte drive embedding in place of absolute-position embeddings. Each mixer uses 32 unit-vector oscillators, a byte-conditioned angular drive and a learned input-dependent coupling to the two ring neighbors. Project the field and neighbor mean on the S1 tangent, take one dt=.25 step, normalize, read out, and apply the existing DirectMonarch FFN with its causal gate. Phase state starts at (1,0) for each oscillator per span, never reindexes and uses 512 float32 bytes across both layers. Patch mode folds identical low-surprise runs and advances the same phase recurrence on retained bytes; no event history required. Fixed-width per-byte arithmetic is O(1), a sequence forward O(T). The training graph retains temporal activations for gradients; the state limit applies to inference.

Before scoring, compare the layer-major full-sequence evaluation with the independent byte-stream execution order; compare identical prefixes under truncation and changed suffix. Require finite outputs, unit norms within 1e-6, fixed 512 B of phase state, and exactly zero maximum logit difference for all 100 seeds and both parity comparisons. Include 269 steps on seed zero to cross the former 256-position limit without rebuilding. No fallback. Measure actual streaming and end-to-end ms/byte, Linux process peak RSS (decimal MB), FP64 BPB, serialized totals and transient/state accounting as in Gate 5B. RSS includes interpreter/backend allocations. Include phase bytes in the serialized continuation-size accounting; regenerated caches and temporary computation are separate.

Score each oscillator policy against the same-seed same-mode cached DirectMonarch policy (plain versus always-on, patch versus patch). PASS requires at least 2.0x measured streaming speedup, BPB delta <=+0.05 and peak RSS <=110% of reference. MIXED requires the RSS bound and at least one of speed or quality. Otherwise FAIL. A policy passes the gate only when it passes all seeds in both modes; aggregate FAIL if all comparisons fail, otherwise MIXED. Report memory-only and both Dense controls separately. One timing per configuration; no CPU-to-GPU extrapolation. Preserve negative and mixed results.
