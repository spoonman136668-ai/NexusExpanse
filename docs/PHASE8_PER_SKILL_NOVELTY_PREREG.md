Use 24 paired 128-byte streams per skill. For the original four domains, draw Phase 7's separate VAL fixtures, with the ASCII swap inverted for A/B in this suite. For C/D/E, reconstruct the same seed-specific tables and draw new windows from separate seeded generators. Check exact 32-byte disjointness against FIT, encounter and CHECK. When the largest predictive prior reaches 0.95, the preceding sparse forecast raised no anomaly, and fewer than 32 forecasts have elapsed since a full-bank call, evaluate only its top expert. Flag the next forecast for full-bank evaluation if the just-observed byte exceeds that expert's calibrated NLL limit. The first forecast is uniform and costs zero calls. Between full-bank calls, a trusted sparse forecast uses the transition row for its admitted state. On returning to full-bank mode, use the current causal prefix's penultimate outputs to re-evaluate the last sparse observation from its saved prior. Use the same log-space BMA mixture as the dense router at every full-bank forecast. This replay corrects the most recent sparse emission, with context bounded by the receiver. ## Suite B — Novelty calibrated by dominant skill

Use the exact Phase 7 same-alphabet fixture generator, including its ASCII bijection for the static A/B answer-byte maps. The novel rule and both resident rules share the four-byte template and alphabet. Their cue-to-answer tables disagree at every key. Before scoring any novel or ID CHECK bytes, calibrate each original domain on its own 24 independent 128-byte ID VAL streams from Phase 7's frozen procedure. The per-skill ceiling is maximum plus the larger of 0.35 BPB and three standard deviations. During detection, find the most frequent top-weight skill in the last 64 forecasts, with ties resolved by bank order. Compare the same bank window-BPB statistic with that skill's ceiling. Preserve the dominant skill, BPB and ceiling for every probe. Use no CHECK or novel data in calibration.

Compare per-skill novelty birth against the original 8 BPB mean detector, fixed K=4, and 32-step continual fine-tuning of the base using the prefix consumed by the per-skill arm. Either birth path registers a 32-step episodic receiver on a positive flag and uses hierarchical BMA after cold restore. Test both detectors on 80 paired ID probes across the seeds. Report false flags, births, held-out novel BPB, answer and routing accuracy, and max original-domain drift with Rule A/B reported individually.
