# Boundary challenge for checkpoint-only transfer

Separate prospective stress test following the compatible singleton-byte method screen. Lock the winning FFN converter from evidence/checkpoint-transfer-screen.json; no reselection of the earlier methods. Repeat on genuine learned 320-token byte-pair donors and a one-step-per-raw-byte receiver. The frozen earlier series and its fallback remain reported independently.

## Data, oracle and arms

Use the Gate 26 repository tree, first 16 eligible 64-byte windows per file and the original 32-byte exact-overlap exclusion. Train donor vocabulary and model only on docs/GATE17_PREREG.md and docs/GATE20_PREREG.md. Validation uses docs/GATE22_PREREG.md and test uses docs/GATE23_PREREG.md. These are fresh file identities relative to the earlier transfer series, all from the same repository. Generate one dense 32-wide two-layer donor per seed, 96 equal-budget next-token updates. Producer records full validation/test reference distributions before exiting. At every raw position retokenize only the observed prefix and sum normalized next-token mass by first byte. This defines a canonical-prefix-boundary reference; it is not exact integration over all tokenizations or all latent partial-token states. Record compression ratio. No teacher forward, tokenization or receipt targets in recipient training or conversion. Receipt probabilities are for scoring only; donor validation BPB sets the common stopping target.

Compare (1) singleton input rows and static first-byte output groups; (2) the same plus a causal two-byte embedding correction, 0.75 times the mean of merged embedding minus singleton final embedding across donor vocabulary spellings ending with that byte pair; and (3) that correction plus static linear interpolation of donor position embeddings by the uniform-vocabulary mean bytes per symbol. No boundary search, token sequence or deep call scheduling in the receiver. The output bridge retains one latent readout component per donor symbol, adding runtime and storage. This is a real interface mismatch with otherwise compatible attention geometry.

## Freeze, selection and decisions

Screen seeds 601–603 on zero-tuning worst KL then mean KL, then method name. Push the screen receipt before the confirmation run. Confirm only the locked winner, basic grouped-readout arm, matched shuffled multi-byte semantic assignments and independently Python-trained scratch on fresh seeds 701–705. If winner is the basic arm execute it once. Do not drop seeds. Pre- and post-tune report KL in bits, argmax agreement, target BPB, coverage, payload bytes, total transfer time and independently verified cold reload. Same held-out Python old-route identity check and explicit caller selection. No receiver validation/test gradients. Stop on validation BPB <= donor +0.02 at zero or every eight updates through 160. Matched time savings are defined only when both arms also reach donor +0.02 test BPB. Record whether either arm is censored. One wall timing per BPE arm, single CPU thread. Separate existing checkpoint from donor creation cost.

Declare BPE near-lossless only on all five seeds with >=99% agreement, <=0.02-bit KL and <=+0.02 BPB versus the canonical-prefix donor on test. Require >=25% total receiver-time savings on every comparable seed, with five matched pairs for a complete joint pass. A quality gain on observed labels cannot substitute for retaining the donor distribution. Preserve failed criteria. This bounds the next handoff: investigate genuine causal length/representation conversion if static lexical and position bridges cannot reproduce the multi-byte donor; never count a reinstalled donor tokenizer as a tokenless solution.

## Independent carrier mapping

The first confirmation crossed all FFNs against the remainder. Freeze a finer intervention on new rule donors 801–805 before executing it. With the selected FFN converter, replace exactly one donor tensor group at a time with the incompatible twin's tensors: byte/position embeddings, attention projections, all norms, both FFNs per layer, or output head. Measure both swap directions before any receiver update. None/all swaps are controls. Report mean own-rule and opposite-rule accuracies and KL to each donor on all ten cases; flag a stand-alone carrier only if the one-group swap achieves >=90% opposite-rule accuracy and <=0.02-bit KL to the opposite donor in every case. Group interactions and gauge dependence limit interpretation. This post-screen mechanistic experiment does not alter the earlier winner.
