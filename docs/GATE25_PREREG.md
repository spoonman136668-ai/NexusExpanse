# Gate 25 preregistration

## Scope and data

This Linux CPU development experiment tests whether a byte-native NexusExpanseByteCore can benefit from a static tokenized donor. It reuses the frozen Gate 4B split at commit `52db0107dfb3ea98c581509af3422594148864b9` with manifest SHA-256 `f5d449a93e1e006e5bda5ca6b6e8b16b50fd6a6098c40f34eff0a82224a3f87d`. Reconstruct and verify the manifest before use. FIT consists of 31 disjoint 256-byte Python source spans. CHECK consists of eight disjoint 256-byte Markdown spans from different files. CHECK is held apart from fitting and is previously used DEV data. No protected or independent holdout is opened.

The development authorization covers seeds 42, 43 and 44, local CPU execution, and publication to the Gate 25 development branch. Approved PyTorch and pytest dependencies may be downloaded to prepare the environment. The experiment uses the checked-in corpus, learns the donor locally, and requires no model, corpus or tokenizer downloads, paid APIs, or donor inference during assimilation. Freeze this document, the implementation, tests and benchmark in one clean source commit. Record the measurement in a separate evidence commit.

## Protocol

- Learn deterministic byte BPE on FIT only. Start with the 256 singleton bytes and merge to 512 distinct entries by descending adjacent-pair frequency, breaking ties on the left then right token ID. Learn across independent spans without pairing across boundaries. Decode each encoded FIT span to its original bytes as a custody check.
- Train a causal dense Transformer donor separately for each seed. Use dimension 128, two layers, four heads, 4x SiLU FFNs, learned token and position tables, untied output and no dropout. Optimize next-token cross-entropy for eight epochs over the 31 BPE spans with one full span per optimizer step. Shuffle each epoch with a local generator seeded with seed plus zero-based epoch. Use AdamW with learning rate .003, weight decay .01 and gradient norm cap 1. Export only its static CPU tensor dictionary and the exact token-to-bytes list. Delete the donor and confirm its weak reference is dead before loading the exported tensors for assimilation. Count and fail on any attempted donor forward pass during static initialization or byte adaptation. Log the donor training count separately.
- Use the native byte core in every arm. Initialize both layers, four heads, 128 dimensions, 4x Monarch FFNs and a 64-byte position table identically for each seed. Set dropout to zero. Keep all FFN gates open, use no online memory or fast-weight updates, and score the neural byte readout.
- **Graft and bridge.** Use the final-byte hidden vector from the native embeddings and first causal attention residual to fit donor embedding coordinates on every static vocabulary pair. Causally mask right padding. Fit only the byte and position embeddings and first attention residual parameters, with Adam at .003 for 96 steps. Use batches of 32 from a fixed seed-25 permutation, cycled six times. Fit in the native coordinate basis with equal row weight and mean squared error. For each of the four compatible matrices (the two FFN projections in each layer), fit independent rank-one group-pair blocks by closed-form SVD and write the DirectMonarch factors.
- **Graft only.** Fit the same four Monarch matrices and omit front-end fitting.
- **Shuffled donor control.** Do the same bridge and graft fitting with independently permuted FFN matrix rows and columns, and independently permuted embedding rows against the fixed vocabulary spellings. Use seed plus 2500. These permutations preserve each input matrix’s singular values and Frobenius norm. The projection into Monarch factors can retain different proportions of the permuted input, so report the relative error both before and after each graft.
- **Scratch Nexus.** Use only the common seeded byte core initialization.
- Adapt every arm for four FIT epochs, 124 student-only byte optimizer steps, with the same epoch shuffle and AdamW settings as above. Each optimizer step consumes the 255 valid transitions of one span in five 51-byte context rows. No cross-span transitions. No corpus scoring updates or fitting choices are driven by CHECK. Measure pooled float64-NLL byte-level BPB over all 2,040 CHECK transitions at 31, 62 and 124 steps. The 124-step BPB is primary. The two bridge arms receive the same extra static fitting budget. Scratch and graft only receive the same byte adaptation budget but do not consume the bridge optimizer budget. Track the shared donor cost and per-arm cost.
- After assimilation, compare exact prefix logits at lengths 32 and 13 for each arm and seed using the first FIT span. Run the existing 100-seed prefix sweep independently. Store the final student checkpoint and use one fresh process per seed to compare each restored model's full tensor and CHECK logit SHA-256 digests to its warm values. Keep the four arms and all seeds, including losses. Keep the model and custody artifacts outside the repository. A completed seed can be reused only with matching source and runtime identity and verified artifact hashes. If stopped in a seed, preserve its incomplete custody and do not automatically replay it. A missing or invalid run receives no scientific score.

## Frozen verdicts

- **ENGINEERING PASS** requires the complete regression and Gate 25 test suite with zero failures, errors and skips, zero failures in the existing 100-seed prefix sweep, exact 0.0 prefix logit error after each arm's initialization, zero donor forward calls in all arms during assimilation and byte adaptation, and exact cold checkpoint and prediction digest parity for all four arms in all three seeds.
- **SCIENTIFIC PASS** requires graft and bridge to improve on scratch by at least 0.05 BPB in each seed, beat the shuffled donor control in each seed and beat or tie graft only in at least two seeds. Use raw unrounded results.
- **SCIENTIFIC MIXED**, after ruling out PASS, requires a strict win over scratch in at least two seeds, or strict wins over the shuffled control in all three seeds without three scratch margin wins. The three-seed reading of the shuffled clause uses the same count as the PASS comparison.
- **SCIENTIFIC FAIL** applies to remaining complete outcomes. It means this static graft and bridge did not establish the requested transfer under this DEV protocol. Neither PASS nor FAIL supports a claim about independent test data, alternative bridges, cached logits, JEPA, or scientific acceptance.
- **DEPLOYMENT NOT RUN.** This gate is limited to the development branch and the reused DEV corpus.

Run from the clean preregistration commit with `PYTHONPATH=".:${PYTHONPATH:-}" python3 benchmarks/gate25_zero_run_assimilation.py --directory PATH_OUTSIDE_REPO`. The benchmark runs `pytest -q` with a JUnit receipt and the original `python3 benchmarks/prefix_causality_dev.py` on the same source and runtime. Optionally use `--seed-limit 1` to finish one complete new seed per invocation with the same directory.
