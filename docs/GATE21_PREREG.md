# Gate 21 preregistration

Base is `7a597ef0b838a7dc9ae37a3415dc4f987cba5529`. Run seeds 42, 43 and 44 on finite synthetic DEV worlds. Verifier programs are sequences of one to three opaque operator bytes from a four-element alphabet. Each primitive transforms residues in a seeded eight-byte alphabet using a fixed arithmetic or bit permutation. The same operations transform strings by applying the byte mapping to each position. The verifier checks exact bytes and returns the actual intermediate strings, the bitwise residual, and its set-bit fraction. All four arms receive identical information. The verifier implements only these fixed operations.

Phase 1 has 32 primitive discovery problems. Phase 2 starts with 12 primitive calibration problems on a disjoint operator alphabet representing the same semantics. Then score 32 new problems, balanced between minimum depths two and three and the original and shifted operator alphabets. Phase 3 begins with 16 distractor problems that permute the effect of the original operator bytes. Cold return restores the post-distractor snapshot in a fresh process and scores 32 new original or shifted-skin compositions. Phase 2 and cold return have disjoint minimum-depth semantic transformation groups, and score distinct inputs. Calibration and distractor problems are recorded separately. Every task allows up to six distinct legal verifier calls and ends immediately on success or exhaustion. Tie order is seed-matched per task.

The bounded agent scores remembered two- or three-step pipelines using Hopfield and episodic primitive observations, plus episodic per-byte composition shortcuts. In gated mode, admit primitive edges and composition records only from exact successes. The unverified control differs only in admission and records the actual trace of every attempted program, without treating an incorrect output as the target. This makes failed traces potentially useful evidence for that control. The fresh gated control resets before Phase 2 and before Phase 3 distractors. The random control searches the same shuffled legal pipeline list. Every policy has the same 40,000-byte adaptive ceiling. Fixed codebooks and local per-query inference are outside the saved state.

PASS requires strict superiority over every control on Phase 2 solved fraction, cold solved fraction, and lower mean calls per solved task in each of the three seeds. Pool that conditional mean across solved Phase 2 and cold scored tasks. An empty solved set produces undefined mean and cannot establish strict superiority. Report the three-step cold fraction separately. Require 3/3 exact fresh-process state and prediction restores plus budget compliance. With engineering qualified, any strict win short of joint PASS gives MIXED. No wins gives FAIL. Do not infer general programming or math ability from this finite fixture.

Commit code, tests and this document before running. Run exactly one segment per invocation with `--directory OUTSIDE --seed N --arm NAME --epoch-limit 1`. Use immutable intent, snapshot and receipt files, checking the parent chain on resume. An ambiguous consumed segment cannot replay. Merge with `--directory OUTSIDE --merge OUTSIDE/result.json` and then publish the raw result in `evidence/gate21-verifier-synthesis-dev-001.json`.
