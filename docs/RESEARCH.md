Imported report: neural only 3.767148 BPB; static memory 2.307542; online episodic + Hebbian 1.732717; dense reference 3.3311. Reported 340000 FFN bytes and 55.301% mean skip. These are not whole-system efficiency metrics. 150681 -> 176582 distinct suffix contexts; no byte accounting. Disjoint-domain exact substring recall does not demonstrate durable learning or generalization. Counts are never overwritten but conflicting observations can change predictions. The fast weight scratchpad resets at the start of each evaluation.

## Next scientific gate: proposed, not executed or frozen

1. Recover the exact original corpus Git SHA/tree, file manifest, split hashes, training configuration, checkpoint custody, and dense benchmark provenance. If unavailable, label Gate 1 non-reproducible and use a new prospectively frozen split; never present a new split as a reproduction.
2. Freeze the dataset, split by source/domain to avoid near-duplicate overlap, seeds, budget, matched training and evaluation protocol, and decision thresholds before any held-out use. Include an explicit duplicate audit. Obtain separate first-use authorization.
3. Evaluate neural dense and Monarch controls (no skip / skip), memory-only static and adaptive n-gram/PPM, neural + static episodic, neural + online episodic without Hebbian, neural + Hebbian without episodic, neural + both. Dense controls also need equal access to memory and online adaptation. Clone identical trained state for each applicable arm. Prediction must precede update. Report prequential and frozen evaluation separately.
4. Measure BPB, complete model parameter/buffer bytes, memory allocated and serialized bytes, peak process/GPU memory, wall time, training and evaluation throughput, memory growth, and cold restart. No speed inference from skip fraction. Use matched time and compute comparisons where feasible.
5. Check conflicting-context interference, held-out domain transfer, retention after reset/reload, and explicit memory budgets. Compare against strongest matched control with predeclared seed-level uncertainty. Provisional Hebbian threshold: at least 0.05 BPB better than online episodic-only on each of three seeds and no >0.02 BPB degradation on familiar cold retention; thresholds need freezing before execution. No claim of intelligence or persistent cognition from BPB.

## Adaptive arbitration development gate (2026-11-24)

Implemented opt-in fixed-share Bayesian two-expert mixing, with one global or four confidence-binned scalar weights. Both use equal prior odds and 1% recovery share (provisional engineering choices, not tuned). The original fusion remains default. The same synthetic fixture, seeds 42–44, training budget and all 12 trained state hashes match `ablation-dev-001.json`. Evidence: `evidence/arbitration-dev-001.json`, measured source `2b5c6af59e0dab300cd94602511f7d047cfae019`, tree `03b27835daad7da42c2d4d2bb76485d13f05256a`. On gated Monarch mean BPB fixed 1.299945, global 0.582283, confidence 0.590262, online memory alone 0.564562. Both adaptive arms beat fixed fusion on all 12 backbone/seed pairs, neither beats memory alone on any pair. This diagnoses fusion interference, not synergistic learning. The global mixer is a useful development comparator, not a promoted architecture. State is caller-owned and nonpersistent; fast weights disabled. No held-out data consumed. Next: stronger neural training and deliberately complementary expert development controls, then persistent fast-weight lifecycle and interference testing under fixed budgets. No scientific gain or speed claim.

## Stronger training and complementary experts (2026-11-24)

Measured source `081f5578b82cc9e5e2abe55f81221871fd24cc3f`, tree `ccf38897a8276fc6e3cd7487305c85640e0d241e`. The attempted 40-epoch development run timed out without a completed artifact; no metrics inferred from it. The 12-epoch run used seeds 42–44, four backbone variants, identical per-fixture training steps per backbone (48 original, 60 complementary), matched cloned states across four neural/fusion arms, and online memory-only controls. CPU runtime 14.36 s. See `evidence/complementarity-dev-001.json`. On the original fixture gated Monarch neural BPB improved from 18.9058 (3 epochs) to 5.091691 (12 epochs), but global fusion 0.564971 still narrowly trails memory-only 0.564562. On the constructed complementary fixture global fusion beats both standalone experts in all 12 pairs (gated Monarch mean 1.540410, memory only 1.804830; dense full mean 1.423586). Confidence-binned fusion also beats both in all 12 pairs. Fixed fusion beats both in none. This is evidence of development-set expert complementarity only. The fixture aligns artificial 32-byte records with neural chunks, contains an intentionally long-distance dependency plus repeated novel records, and uses a fixed eight-byte episodic context; it does not isolate the causal contribution of the marker, compare with longer-context or stronger PPM controls, or establish transfer. Equal steps are not equal compute. No full training convergence, held-out data, or scientific first-use. No architectural default changed. Next: persistent fast weights with checkpoint identity, cold replay, interference controls; then real-data and stronger context-matched controls before any qualification.

## Persistent Hebbian adaptation development gate (2026-11-24)

Opt-in CPU float32 fast-state checkpoint, with exact neural content/topology/source/configuration identity, versioned bounded binary tensor payload, corruption checksum, exclusive file creation, and validation before restore. Default evaluation reset unchanged; call with `reset_fast_state=False` to preserve restored state. Update count and tensor round-trip exactly; fresh-process prediction equivalence and continued adaptation tested. Checksum is not authentication, and a trained backbone must be separately available. No complete atomic snapshot of episodic/arbitration/neural state or concurrent writer support. The original episodic-memory docstring incorrectly promised zero forgetting; corrected.

Measured development source `0fdf20cef830fec196d525fc2c5bc615b359c7a4`, tree `e6e7f1cd507921128398ba5760f383ca2e1cc1d1`; `evidence/fast-retention-dev-001.json`. Three gated Monarch seeds, 12 training epochs/48 steps, identical backbone per arm, no episodic memory or arbitration, two 208-byte repetitive conflicting fixtures A/B. Frozen evaluation after A learning, restored checkpoint, reset control, and after B learning, plus no-write frozen control. Checkpoint 32,966 bytes (32,768 tensor bytes), under provisional 40,000-byte budget. All three seeds restore exact score and improve familiar A after local adaptation relative to reset, but all three lose A accuracy after B learning (+0.583, +0.271, +0.549 BPB); frozen control unchanged. B accuracy improves with B learning. This is a deliberate repeated-pattern diagnostic, not novel transfer or a matched strongest-control scientific trial. No held-out data consumed. Next: distinguish global decay from conflicting update interference, compare bounded context-conditioned fast states against same-budget controls with frozen development criteria; do not promote persistence as interference-resistant learning.
