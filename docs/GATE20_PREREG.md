# Gate 20 preregistration

Run seeds 42–44 on the fixed order Math, Code, Science/Prose, Cold Return to Math and Code. Use the exact existing Gate 10 math and repository-code rows, sampling 32 training and 16 distinct evaluation blocks for each domain. Use 24 unchanged 48-byte blocks sampled from Gate 4B's frozen prose split for interference training. Record every block digest and prior manifest digest. Compare three matched isolated unified runtimes per seed with the same initialized and frozen width-32 attention weights, window 64 and empty compact bigram prior. Each block starts with a cleared context. The experiment studies the adaptive store with frozen neural computation.

During training, keep ordinary unified online autoregressive scoring, bounded episodic writes, and arbitration. Expose the latest two observed context bytes and realized next byte to the decoupled Hopfield memory at every sixth observed transition and the end of each block. The primary score is the existing unified mixture BPB. That mixture uses the neural/patch and episodic distributions. Hopfield remains a decoupled store.

The opt-in sleep budget gives each arm 24,000 bytes of episodic storage and up to 44 Hopfield slots. Check the sum of the serialized episodic and relational payloads, 24 arbitration bytes and the bounded transient ledger against 40,000 bytes. Frozen weights, codebooks, empty bigram prior, and model stream scratch tensors are outside the adaptive budget. At each training boundary, retain at most 16 high-surprisal observed transitions from the first and last three predicted bytes in a block. Deduplicate by raw context and outcome. The sleep arm replays these observed transitions to both memory mechanisms and drops the lowest-support eighth of each memory's rows, ranked by dominant target support and then total support. No-sleep keeps ordinary bounded online memory. Random-prune receives no replay and deletes physically random-ranked rows from the same types of stores. For sleep and random labels, find the highest jointly attainable physical byte count at or below the provisional sleep size and prune additional ranked sleep rows only if needed to reach that exact match. Reserve one episodic context in the matching pass for exact row-size accounting. Log all replay choices and removals. All boundary choices occur before cold scoring.

Run one phase per command with `--directory OUTSIDE --seed N --epoch-limit 1`. Freeze the preregistration, implementation and unit tests before running. Hash each immutable checkpoint and verify its parent chain. Require a fresh-process match of weights, adaptive state and continuation prediction digests for every arm on cold return. Cold scoring freezes all adaptive writes; test Math and Code in the same order and report individual and transition-weighted combined BPB.

PASS requires exact restores, equal post-boundary physical bytes for sleep and random control, budget qualification, and at least .05 lower combined cold BPB versus both controls in each seed. With engineering qualified, any positive margin short of this joint requirement is MIXED. No positive margins means FAIL. These conclusions apply to the reused DEV blocks.
