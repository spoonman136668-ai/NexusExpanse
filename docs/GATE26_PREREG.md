# Gate 26 preregistration

## Scope and data

Use the exact Gate 25 base `eca9408aca0e2fd4f0fced57eb5beeb8106d3730` and its evidence SHA-256 `84c02791529f88f229d09448b7c972920c095147766654d67ab97d1deec43572`. Reuse Gate 4B commit `52db0107dfb3ea98c581509af3422594148864b9` and manifest SHA-256 `f5d449a93e1e006e5bda5ca6b6e8b16b50fd6a6098c40f34eff0a82224a3f87d`. Verify the manifest against Git. FIT is 31 Python spans and CHECK is eight distinct Markdown spans, each 256 bytes. CHECK is reused DEV data. Scope is Linux CPU, seeds 42–46, no external downloads or paid APIs, and publication to the Gate 26 development branch.

Use the same 512-entry raw-byte BPE fit, 128-dimensional two-layer four-head dense donor with 4x SiLU FFNs, and eight donor FIT epochs as Gate 25. Train one donor per seed and record its training calls separately from the offline inference call. Compare serialized donor hashes to Gate 25 on the three overlapping seeds. Each student starts at the same seeded NexusExpanseByteCore weights in its seed, with two layers, 128 dimensions, four heads, 4x DirectMonarch FFNs, 64 positions, zero dropout and `enable_skip=False`. Use fixed evaluation geometry for exact ungated prefix comparisons. No online memory or fast-weight updates.

## Initialization and arms

- **scratch_nexus** trains the untouched initial student with next-byte cross-entropy.
- **shuffled_full_graft** uses the full static fitting pipeline with independent FFN row and column permutations, packed attention row permutations within Q/K/V sections and attention column permutations, and the corresponding permutations of projection biases and norm pairs. Permute the donor embedding rows against the fixed vocabulary. Use seed plus 2600. Train with cross-entropy.
- **zero_run_full_graft** copies the four attention projection tensors and the two LayerNorm weight/bias pairs per layer directly. Factorize the four donor FFN matrices with the Gate 25 blockwise rank-one SVD. Use the Gate 25 96-step bridge with the original fixed vocabulary order, Adam .003, and first-layer causal final-byte readout. Only the byte and position tables are optimized by the bridge so the copied tensors stay bit-exact at initialization. All normal trainable parameters participate in the subsequent cross-entropy adaptation.
- **offline_byte_kl** uses the scratch student and cross-entropy plus 0.5 times KL from the static byte cache.
- **hybrid_graft_plus_kl** uses the identical full-graft warm start and the same cross-entropy plus 0.5 times offline byte KL.

Each arm takes exactly 124 student updates, four FIT epochs, with the same epoch shuffle (seed plus zero-based epoch) and the Gate 25 AdamW settings (.003 learning rate, .01 weight decay, gradient norm cap 1). Each step consumes five 51-byte context rows for one span, with 255 next-byte targets and no cross-span transition. Pool FP64 next-byte log losses over all 2,040 CHECK transitions at 31, 62 and 124 steps. The 124-step BPB is primary. Student steps and byte targets match. Donor training, static fitting, and cache export have their own compute costs. The teacher can use the whole observed span prefix while the student resets every 51 bytes.

## Offline cache

Use the operator-approved canonical-history approximation to the donor's full history model. Summing every valid token history would require up to about `7.3e40` histories for a single FIT prefix. For a byte prefix ending before offset `t`, consider every possible final token start `s <= t`. Encode only the observed bytes before `s` with the fixed, learned BPE ranks. This gives one canonical completed-token history at each boundary. The token trie supplies every candidate whose spelling starts with the observed suffix `raw[s:t]` and has at least one further byte. Add the product of the canonical history's joint likelihood and the conditional likelihood of each matching token to the bin for that token's next byte. The boundary `s=t` includes all next tokens. Normalize the 256 bins in float64. This is the exact sum within the selected histories. Since the donor has no BOS symbol, assign a fixed add-one-smoothed first-token distribution from the 31 canonical FIT encodings. That prior and the donor weights are fixed while extracting targets. No byte at or beyond `t` enters the relevant conditioning path.

Execute one causal donor forward call per seed on a right-padded batch of maximal canonical token paths, selecting the needed logits at their causal prefix positions. Use only FIT spans. Export a versioned binary cache with a 45-byte header binding ordered FIT bytes and one row of 16 uint8 byte IDs and 16 little-endian float16 probability masses per position, including span offset zero. Select the largest probabilities with ascending byte ID for ties. Commit only the evidence receipt containing the cache SHA-256 and file size. Later reopen the cache by its ordered FIT identity and expected digest, normalize the retained masses to one, and score sparse teacher-to-student KL against the full 256-byte student softmax. The cache omits the tail and has float16 rounding. Deleted donor and cache verification are required before any student step. The zero-run arms never consume cache targets. The donor guard must count zero calls throughout all student preparation and training.

## Frozen verdicts and custody

- **ENGINEERING PASS** requires all 176 prior tests and all new Gate 26 tests to pass with zero failures, errors or skips, and 0/100 failures in the existing prefix sweep. For all 25 arm-and-seed runs, prefix error must be exactly 0.0 before and after adaptation for both truncation and altered suffix probes. Restore all students in a fresh process per seed and require exact checkpoint tensor and full CHECK-logit digests. Every copied dense tensor must match exactly at initialization. Each cache must have exactly one offline donor forward, normalized rows before top-k selection, a verified hash, and a dead donor reference before student work. Zero donor forwards are allowed during assimilation and student training.
- **SCIENTIFIC PASS, zero-run track** requires the full graft to beat scratch by at least 0.05 BPB in at least 4/5 seeds and to beat the shuffled full graft in 5/5 seeds.
- **SCIENTIFIC PASS, offline byte-KL track** requires at least one same KL arm to beat scratch by at least 0.10 BPB in 5/5 seeds and to beat the full graft in at least 4/5 seeds.
- **SCIENTIFIC MIXED** means just one required condition was met for the zero-run track or for at least one KL arm without a passing KL arm. **SCIENTIFIC FAIL** means neither required condition was met for the zero-run track or for either KL arm. Use raw unrounded BPB. An incomplete or invalid scored run has no scientific verdict. These are comparisons on the reused DEV split with the approved canonical-history approximation.
