## Architecture and engineering

Use two layers, four heads, dimensions 64 and 128, always-on DirectMonarch with multiplier 2 and no dropout. For a head, FP64 state is indexed by value then key. Project Q/K/V and two sigmoid gates per head. Normalize each key, use the residual against the **previous** state, add its gated outer product to the decayed state, and read with Q. For a unit key the homogeneous update has eigenvalues alpha and alpha minus beta. Finite learned gates and nonorthogonal keys can limit capacity and retention. Exact evaluation parity is a separate property from associative retrieval accuracy. The differentiable training path solves for the causal residual writes in parallel with a unit lower triangular system. It is quadratic in sequence length. Evaluated batch and streaming execution share the recurrent kernel. Streaming work and retained state per byte are constant in history length, with no KV cache.

Before any objective training, require exact prefix logits and hidden states at cuts 1, 7, 13, 25 and 31. Require exact logits, hidden and FP64 softmax at every streamed byte versus batch. Use 32 random bytes in each of seeds 0 through 49 at each dimension, batch 1, single-thread deterministic PyTorch CPU. Count the retained matrix bytes at every step. Expected two-layer state sizes are 16,384 and 65,536 bytes. An engineering failure blocks training.
